# Lab 03 — Backup Trust and Recovery

Scenario: BKP-01 contains recent backups but was accessed during the incident. VAULT-01 contains an older isolated copy.

Student mission:
- Determine whether BKP-01 can be trusted without further validation.
- Review evidence of repository modification.
- Verify isolation evidence for VAULT-01.
- Perform a controlled restore test using disposable lab data.
- Record integrity checks and recovery result.

Success condition: select a recovery source based on evidence rather than recency alone.
