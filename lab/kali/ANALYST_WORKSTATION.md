# Kali Analyst Workstation

KALI-ANALYST is a blue-team investigation workstation in this exercise.

## Tasks
- Calculate and verify evidence hashes.
- Review CSV and text artifacts.
- Build a unified timeline.
- Inspect provided packet captures when added to the challenge.
- Compare network events with Windows authentication and process events.
- Document conclusions with artifact name and timestamp.
- Validate that conclusions distinguish fact, inference, and attacker claim.

## Suggested defensive utilities
Standard text-processing tools, Wireshark/tshark, hashing utilities, and timeline-analysis tools may be used. The challenge does not require exploitation or malware execution.
