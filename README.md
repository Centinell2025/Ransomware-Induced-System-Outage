# DeadVault

**HTB Sherlock — Ransomware-Induced System Outage**

Enterprise DFIR investigation challenge focused on ransomware-induced business disruption, evidence correlation, backup resilience, and recovery decision-making.

## Challenge concept

A ransomware incident has brought critical enterprise systems offline. The analyst must correlate endpoint, identity, network, server, and backup evidence to reconstruct what happened and determine whether a trustworthy recovery path exists.

This challenge is designed so that conclusions must be supported by evidence. An attacker claim is not, by itself, proof of data exfiltration.
